Política de privacidad

ToolBox Gratis

Última actualización: 13 de noviembre de 2026.

En ToolBox Gratis queremos ofrecer herramientas sencillas y gratuitas, respetando la privacidad de las personas que visitan nuestra página.

1. Datos que introducen los visitantes

Las calculadoras, el conversor de temperatura, el contador de palabras y los generadores funcionan directamente en el navegador del visitante.

El código actual de estas herramientas no envía los números, textos ni resultados introducidos a un servidor propio. No solicitamos nombres, teléfonos, direcciones ni cuentas para utilizar las herramientas.

2. Preferencia de tema

La página permite elegir entre modo oscuro y modo claro. Para recordar esa preferencia, utiliza el almacenamiento local del navegador (localStorage). Esta preferencia se guarda en el dispositivo del visitante y no se utiliza para identificarlo.

3. Alojamiento y datos técnicos

Esta página está alojada mediante GitHub Pages, un servicio proporcionado por GitHub.

GitHub informa que registra y almacena las direcciones IP de las personas que visitan sitios alojados en GitHub Pages por motivos de seguridad, incluso si no tienen una cuenta de GitHub.

Este tratamiento depende de GitHub y no está controlado directamente por ToolBox Gratis.

Puedes consultar la información de GitHub en su Declaración general de privacidad .

4. Cookies y publicidad

Actualmente ToolBox Gratis no tiene anuncios publicitarios instalados ni utiliza Google Analytics.

Si en el futuro incorporamos publicidad de terceros, como Google AdSense, actualizaremos esta política antes de activarla para explicar qué proveedores intervienen, qué cookies o tecnologías pueden utilizar y cómo pueden gestionarse las preferencias de privacidad.

5. Servicios externos

El alojamiento de la página depende de GitHub Pages. Los servicios externos pueden tener sus propias políticas y condiciones de privacidad.

Recomendamos consultar las políticas de esos proveedores para conocer cómo tratan la información.

6. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones de la página o se incorporen nuevos servicios. La fecha de actualización aparecerá al principio del texto.

7. Contacto

Actualmente ToolBox Gratis no dispone de formulario de contacto ni solicita datos personales para utilizar sus herramientas.
